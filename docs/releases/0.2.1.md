# AI Lover v0.2.1

交付 Windows x64 安装版、便携 ZIP 和 Android 测试 APK。

## 项目整理

- 平台入口归入 `apps/android` 和 `apps/windows`；共用界面归入 `packages/ui`，角色、提示词、上下文和服务商规则归入 `packages/core`。
- 删除独立网页服务、PWA、Service Worker、Docker/Compose、网页部署命令及旧演示资料。
- 重写 README、平台说明和开发文档，构建命令统一为 `android:*`、`windows:*`；共用界面仅作为客户端内部构建产物。
- 保留双方描述分离、第一人称当事人视角、旧 AI 回复上下文隔离、双服务商密钥入口和简洁聊天界面。

## OPPO A32 验收

已通过独立 Windows ADB 端口连接并授权的 OPPO A32，读取应用原记录后覆盖安装 0.2.1。核对确认：1 位对象与全部 22 条消息的原文字段保持一致；11 条旧 AI 回复已排除出后续模型上下文。对象原描述保留，「对我的描述」独立初始化。

真机表单显示双方描述，聊天和表单在 360 px 宽度下没有横向溢出。升级后已恢复本机加密密钥，设置不含明文密钥；两家服务商入口可用。使用手机保存的 MiMo 配置完成一次真实原生连接测试，模型实际响应约 2.7 秒，仅发送测试指令，不发送私人聊天原文。该次耗时不代表稳定延迟。

手机聊天快照和设备检查资料仅保存在本机忽略目录，不进入源码、安装包或 GitHub。
