## 每个手机宽度的完整流程

1. 检查真实应用健康接口，进入手机聊天列表。
2. 用触摸操作打开创建表单，创建动物伙伴，设置双方身份、种类、性格及离异阶段。
3. 返回列表，通过底部导航进入设置。
4. 填写测试 Key，读取受控模型列表，选定模型，验证测试请求使用该模型并保存设置。
5. 进入通讯录，打开对象资料，通过“聊一聊”进入当前对象会话。
6. 输入并发送消息，显示受控 SSE 正文；检查请求仅包含当前对象和本轮消息。
7. 返回列表，刷新，再打开对象，确认设定和聊天记录恢复。

在创建、设置、通讯录和聊天阶段检查水平溢出；操作前检查创建、保存、输入及发送控件在视口内，并实际触摸操作以确认可点击。

## 复现

```bash
npm ci
npx playwright install chromium
npm test
npm run build
npm run test:e2e
```

只运行手机流程：

```bash
npm run test:e2e -- --project=mobile-chromium
```

README 的四张手机截图在独立、无用户数据的浏览器上下文中拍摄，视口为 390 × 844、DPR 为 2；展示图由 `npm run docs:gallery` 从这些截图生成。

## 证据边界

移动端检查属于浏览器触摸模拟，没有真实 iPhone / Android 硬件或 Safari 引擎测试。供应商模型列表、连接验证和聊天输出使用受控响应；应用健康接口和生产页面是真实服务。没有真实供应商 API Key，不据此宣称模型质量、计费或线上首字速度已验证。
