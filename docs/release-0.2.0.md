# AI Lover v0.2.0

交付范围：Windows x64 安装包与免安装 ZIP、Android 测试 APK。桌面与安卓独立运行，只支持小米 MiMo 和硅基流动国内站。

## 修复

- 创建/编辑对象拆为「对 TA 的描述」「对我的描述」，分别保存学历、兴趣、职业等设定；旧补充资料保留并归属于对象。
- 明确第一人称角色：回复中的「我」是当前对象，「你」是用户，直接以关系当事人的视角交流。
- 保留旧聊天原文，升级时将旧 AI 回复排除出模型上下文，防止错误角色继续影响新回复。用户原话保留；新版回复正常参与后续记忆。
- 移除备份导入导出及对应插件；聊天页删去重复说明，使用简洁输入栏。模型设置同时提供两家服务的密钥入口。
- 前端、Node 网关及安卓原生网关均拒绝硅基流动国际站。旧国际配置迁移时丢弃旧密钥与模型，不向国内端点发送国际密钥。

## 构建与密钥

Windows 安装包和 Android APK 不内置用户 API Key。构建只包含允许的应用文件，不包含 `.env`、聊天快照、设置、设备资料或签名私钥。发布流程检查源码历史及安装包中的密钥候选，并生成 SHA-256 校验文件。

用户自行填写的密钥在设备上加密保存；Windows 使用稳定应用协议保留聊天和设备加密密钥，本机模型网关只监听 loopback 并要求随机认证令牌。安卓关闭系统云备份与设备数据迁移。

Android 为固定调试签名测试包，沿用本机测试签名，以支持覆盖更新；签名材料仅保存在 Actions Secret，不进入仓库。Windows 未配置代码签名证书。升级时请保留应用数据，避免卸载清除聊天。

## 验证

已完成本机类型/格式检查、166 项自动测试、13 条浏览器流程和 9 项安卓 JVM 测试；安卓 Lint 与 APK v2 签名检查通过。浏览器覆盖双方描述保存、旧聊天升级、密钥加密恢复、请求隔离、取消/重试、长对话及 320/390/412 px 的键盘缩小布局。

真实 MiMo 仅使用虚构资料验证两轮：

| 场景 | 回复样本 | 首正文 / 总耗时 |
| --- | --- | --- |
| 区分双方学历与兴趣 | 「我是文学硕士，平时喜欢弹钢琴；你是计算机本科，喜欢爬山。」 | 9.2 / 9.6 秒 |
| 关系当事人的口吻 | 「我也想你呀，听到你这么说心里暖暖的。」 | 7.1 / 7.8 秒 |

这些样本验证本次提示词与请求链路，不能代表稳定延迟或所有后续生成。硅基流动使用模拟响应验证，未使用真实硅基账户测试。

Windows 原生构建与桌面重启验收由 GitHub Actions 执行，完成结果会更新到本记录。

本轮 ADB 没有识别到已连接并授权的 OPPO，因此尚未核查该手机的具体聊天原文、安装更新与真机复测。旧聊天的通用迁移已通过自动回归，手机连接后仍需完成设备验收。
