## 主文案

最近做了一个小软件，叫「知心 · AI Lover」。出发点很简单：有些时候，我想找个地方慢慢说完今天的心情。项目做累了，遇到一点小开心，或是心里有些乱，都可以从一句话开始。

我希望它先接住情绪，再跟着聊天的节奏往下说。创建朋友时，有 16 种性格可以选，最多组合 3 种；还有 6 个关系阶段，按自己的想法手动选择，留一点空间给不同的相处方式。

这次我把「对 TA 的描述」和「对我的描述」分开了。TA 的学历、爱好属于 TA，我的经历和聊天偏好属于我，帮助模型更清楚地理解彼此的身份。

界面也尽量做得简单一点，把空间留给消息和输入。累的时候，打开它说两句就好。

现在支持 Android 和 Windows x64，OPPO A32 已测试可用。对象资料和聊天保存在当前设备，暂时没有自动跨设备同步。

使用时需要自备小米 MiMo 或硅基流动国内站 API Key。密钥在本机加密保存，模型调用费用由自己的服务商账户承担。

源码和安装包都放在 GitHub，想体验可以下载试试。图里的对话是虚构示例，展示的是我想做的陪伴方式。也欢迎把使用感受告诉我，慢慢把它做得更顺手。
